## Summary
The paper proves the first non-relativizing NP-hardness results for two long-open meta-complexity targets. First, it resolves Ko's 1991 question by proving NP-hardness of MINLT (learning efficient programs), the Occam-learning regime that sits strictly between proper and improper PAC learning, under randomized polynomial-time many-one reductions. Second, it proves NP-hardness (and hardness of approximation within $(\log N)^\epsilon$) of the partial-function variants $\mathsf{MCSP}^*$, $\mathsf{NC}^1\text{-}\mathsf{MCSP}^*$, $\mathsf{MKTP}^*$, $\mathsf{MINKT}^*$, plus the average-case variant $\mathsf{AveMCSP}$, also under randomized reductions. The unifying technical device is an algorithmic-information (Kolmogorov-complexity) argument showing that no small program can "know" many random functions, which turns a black-box pseudorandom generator (DP and Nisan-Wigderson) into a one-time encryption scheme secure against programs that do not know a hidden key.

## Key definitions and results

### The two headline targets
- **MINLT** (Ko 1991), the Occam-learning search problem for efficient programs. Input: samples $((x_1,b_1),\dots,(x_m,b_m); 1^t, 1^s)$ with $x_i \in \{0,1\}^n$, $b_i \in \{0,1\}$. Question: does there exist a $t$-time program $M$ of size $s$ consistent with all samples ($M(x_i)=b_i$)? (Section 1.1, p. 2; formal gap version Definition 7.1, p. 22.) Ko proved no relativizing proof shows NP-hardness of MINLT (Section 1.1, p. 2).
- **$\mathsf{MCSP}^*$** (the partial-function MCSP). Input: a partial function $f : \{0,1\}^n \to \{0,1,*\}$ given as a truth table of length $2^n$ over the alphabet $\{0,1,*\}$, plus a size parameter $s$. Question: is there a circuit of size $s$ computing some total function consistent with $f$ (agreeing on all $x$ with $f(x)\neq *$)? (Section 1.2 p. 4; Definition 8.4 p. 30.) Levin reportedly delayed his NP-completeness paper hoping to prove NP-completeness of MCSP; the second NP-complete problem in Levin 1973 was $\mathsf{DNF}\text{-}\mathsf{MCSP}^*$ (Section 1.2, p. 4).

### Theorem 1.1 (learning programs / MINLT), Section 1.1 p. 2, restated as Theorem 7.2 p. 23
Under randomized polynomial-time one-query reductions, given a size parameter $s$ and a distribution $\mathcal{E}$ with $\mathrm{supp}(\mathcal{E}) \subseteq \{0,1\}^n \times \{0,1\}$ (encoded by a circuit), it is NP-hard to distinguish:
- **Yes:** there is a polynomial-time program $M$ of size $s$ with $\Pr_{(x,b)\sim\mathcal{E}}[M(x)=b]=1$; moreover $M$ computes a linear function over $\mathrm{GF}(2)$.
- **No:** for every program $M$ of size $s\cdot n^\epsilon$, $\Pr_{(x,b)\sim\mathcal{E}}[M(x)=b] \le \tfrac{1}{2} + 2^{-n^{1-\delta}}$, for an arbitrary constant $\delta>0$ and $\epsilon = 1/(\log\log n)^{O(1)}$.

Three points the author stresses (Section 1.1, pp. 2-3): (1) the No case rules out even time-unbounded programs, so it really is a statement about description size, not running time; (2) the correlation bound $\tfrac12 + 2^{-n^{1-\delta}}$ is exponentially small, far stronger than the usual $\tfrac12 - \epsilon$ hardness-of-learning-with-error results; (3) the gap $n^\epsilon$ between Yes-size $s$ and No-size $s\cdot n^\epsilon$ comes "somewhat close" to the improper-learning regime. Improving $n^\epsilon$ to $1.01n$ would exclude Heuristica (Appendix A, Proposition A.1, p. 33: under size-expanding reductions a $1.01n$ gap with No-correlation $\tfrac12 + \tfrac{1}{5s}$ gives $\mathsf{P}\neq\mathsf{NP} \iff \mathsf{DistNP}\not\subseteq\mathsf{AvgP}$).

### Theorem 1.2 / Theorem 8.5 (partial meta-complexity), Section 1.2 p. 5, Section 8 p. 30
Under randomized polynomial-time many-one reductions, $\mathsf{MCSP}^*$, $\mathsf{NC}^1\text{-}\mathsf{MCSP}^*$, $\mathsf{MKTP}^*$, and $\mathsf{MINKT}^*$ are NP-hard, and NP-hard to approximate within a factor of $(\log N)^\epsilon$ on inputs of length $N$ for a universal constant $\epsilon>0$. The Yes/No formulation (Theorem 1.2): given partial $f:\{0,1\}^n\to\{0,1,*\}$, a size $s$, and a distribution $\mathcal{D}$ over $f^{-1}(\{0,1\})$:
- **Yes:** there exist an $s$-time program $M$ of size $s$ and a circuit $C$ of size $\tfrac{s}{\log s}$ and depth $O(\log s)$ with $\Pr_{x\sim\mathcal{D}}[M(x)=f(x)] = 1$ and $\Pr_{x\sim\mathcal{D}}[C(x)=f(x)]=1$.
- **No:** for every program $M$ of size $s\cdot n^\epsilon$ and every circuit $C$ of size $\tfrac{s}{\log s}\cdot n^\epsilon$, both succeed with probability $\le \tfrac12 + n^{-\epsilon}$.

Definitions of the variants (Definition 8.4, p. 30): $\mathsf{NC}^1\text{-}\mathsf{MCSP}^*$ restricts the size-$s$ circuit to depth $c\log s$; $\mathsf{MKTP}^*$ asks whether some $y$ consistent with a partial string $x$ has $\mathrm{KT}(y)\le s$; $\mathsf{MINKT}^*$ asks whether some $y$ consistent with $x$ has $\mathrm{K}^t(y)\le s$. KT-complexity is defined for sublinear time via random access to the program (Definition 4.1, p. 13, following ABKMR06): $\mathrm{K}^{t,A}(x\mid y)$ is the shortest $d$ such that $U^{A,d,y}$ outputs $x_i$ on input $i$ within time $t$, and $\mathrm{KT}(x)=\min\{s+t \mid \mathrm{K}^t(x)\le s\}$.

The size parameter $s$ in Theorem 1.2 is exponential in $n$ (i.e. $s=2^{\Theta(n)}$), which the author argues is inevitable unless NP has randomized sub-exponential algorithms (Section 1.2 footnote 9, p. 6). The crucial trick: the partial function $f$ has truth table of length $2^{O(n)}$ but the NP-hardness reduction runs in time $N^{O(1)}$ with $N$ the truth-table length, so it needs $n=O(\log N)$ (Section 2.2, p. 6, and Lemma 8.3 which produces $|x|=O(\log\nu + \Delta^2)=O(\log n)$).

### AveMCSP (average-case MCSP), Definition 8.6 (San20) and Theorem 8.7, Section 8 p. 31
$\mathsf{AveMCSP}$ asks, given the truth table of total $f:\{0,1\}^n\to\{0,1\}$, parameters $s$ and $\delta$, whether there is a size-$s$ circuit $C$ with $\Pr_{x}[C(x)\neq f(x)]\le\delta$. Theorem 8.7: $\mathsf{AveMCSP}$ is NP-hard under randomized reductions; likewise computing average-case time-bounded Kolmogorov complexity $\mathrm{K}^t_\delta(x)$ on input $(x,t,\delta)$ is NP-hard. The proof modifies the $\mathsf{MCSP}^*$ reduction by replacing each $f(x)=*$ with a uniformly random bit (Section 8, p. 31).

### Supporting hardness target: CMMSA, Section 5
The **Collective Minimum (Weight) Monotone Satisfying Assignment** problem (Definition 5.1, p. 15) generalizes MMSA (ABMP01, DS04) to a collection $\Phi=\{\varphi_1,\dots,\varphi_m\}$ of monotone formulas with a weight function $w$. Distinguish Yes (an assignment of weight $\le s$ satisfies all $\varphi_j$) from No (every assignment of weight $\le g\cdot s$ satisfies $<\epsilon$ fraction). Theorem 5.2 (p. 16): for any $\beta>0$ there is $\alpha>0$ such that for $\omega(1)\le\Delta(n)\le 2^{(\log n)^{1-\beta}}$, CMMSA is NP-hard with gap $\Delta(n)^\alpha$, degree $\Delta(n)$, and soundness $\Delta(n)^{-\alpha}$ over monotone DNFs. The reduction comes from the Sliding Scale Conjecture PCP of DFKRS11 / DHK15 (Lemma 5.3, p. 16) composed with the Dinur-Safra MaxCSP-to-MMSA reduction. The "locality" of CMMSA (each formula depends on $\le\Delta$ of $n$ variables, with $\Delta=(\log n)^{1/2}$) is what lets the reduction shrink the input length of $f$ to $O(\log N)$.

### Heuristica connection, Appendix A
Proposition A.1 (p. 33): if there is a randomized polynomial-time size-expanding reduction from an NP-complete problem to the learning problem with a $1.01n$ gap and No-correlation $\tfrac12 + \tfrac{1}{5s}$, then Heuristica does not exist, i.e. $\mathsf{P}\neq\mathsf{NP} \iff \mathsf{DistNP}\not\subseteq\mathsf{AvgP}$. The proof uses HN21 weak agnostic learning from average-case easiness and the sampling-depth machinery (Definition A.2, Lemmas A.3 and A.4).

### Ko's relativization barrier and how it is overcome, Appendix B
Proposition B.1 (p. 36): there is an oracle $A$ with $\mathrm{Gap}_{t,2,\epsilon}\mathsf{Learn}^A \in \mathsf{BPP}^A$ and $\mathsf{NP}^A \not\subseteq \mathsf{BPP}^A$; hence Theorem 7.2 is non-relativizing. This extends Ko's deterministic barrier (Definition B.2) to randomized reductions via $\mathsf{GapMINLT}$ (Fact B.3) and a relativized construction (Lemma B.4) giving an oracle $\mathcal{O}=A+B$ where $\mathsf{GapMINLT}^{\mathcal{O}}\in\mathsf{P}^{\mathcal{O}}$ but $\mathsf{NP}^{\mathcal{O}}\not\subseteq\mathsf{BPP}^{\mathcal{O}}$ for $g(t)=\log^4 t$.

## Techniques and proof ideas

The single reusable engine is the **algorithmic information extraction lemma** (Section 6). The author quantifies what a program "knows" via conditional Kolmogorov complexity: a program $M$ knows $f_i$ if $\mathrm{K}(f_i \mid M) \le \theta$ for a threshold $\theta=2nk$ (Section 2.1, p. 9). The lemma (informal Lemma 2.1, formal Lemma 6.1, p. 18) says: given strings $f_1,\dots,f_n$ that are Kolmogorov-random ($\mathrm{K}(f_T) \gtrsim |T|\cdot\lambda$ for all $T$), any program $M$ has a small "known" set $B$ with $|B| \lesssim |M|/\lambda$, and outside $B$ the program cannot distinguish the pseudorandom generator output from uniform.

The mechanism that hides information:
1. **k-wise direct product generator $\mathrm{DP}_k$** (Hir20b), Section 2.1 p. 7. For $f\in\{0,1\}^\lambda$ (a row vector over $\mathrm{GF}(2)$) and matrix $z$, $\mathrm{DP}_k(f;z)=(z, f\cdot z)$. It is linear in $z$ for fixed $f$ (gives the GF(2)-linearity of the Yes case) and satisfies a reconstruction property (Eq. 1, p. 8): if $D$ $\epsilon$-distinguishes $\mathrm{DP}_k(f;\cdot)$ from uniform then $\mathrm{K}^D(f)\le k + O(\log(\lambda k/\epsilon))$. So $\mathrm{DP}_k$ is a one-time encryption scheme secure against any $D$ that does not know $f$ (in the sense $\mathrm{K}^D(f)\gg k$).
2. **Secret sharing for monotone formulas** (Lemma 4.5, ISN93 / BL88), Section 4.2 p. 15. For monotone $\varphi$ there is an efficient $(\mathrm{Share},\mathrm{Rec})$ scheme whose authorized sets are exactly the satisfying sets of $\varphi$; each share has length $\le|\varphi|$ and reconstruction is GF(2)-linear.
3. **Composition** (Section 2.1, pp. 7-9): reduce MMSA / CMMSA to learning by sharing a secret bit $b$ among $n$ parties using the formula's secret-sharing scheme, then hiding each share $s_i$ in the input via $\xi_i = \mathrm{DP}_k(f_i;z_i)\oplus(0^{\lambda k}, s_i)$. A program that knows the $f_i$ for an authorized set $T$ (a satisfying assignment) can read those shares and reconstruct $b$, so a small satisfying assignment gives a small consistent program (completeness). Conversely the extraction lemma forces any small program to know only an unauthorized set, and by the privacy of the secret sharing scheme its output is independent of $b$, hence correlation $\tfrac12$ (soundness).

The proof of the extraction lemma (Section 6) uses a careful hybrid argument (Yao's next-bit predictor) combined with **Trevisan-Vadhan advice** (TV07): the distinguisher $D$ is a randomized algorithm taking $a$ bits of advice, and the reconstruction works with $\mathrm{K}(f_1\mid M)\lesssim k+a$ rather than requiring the full description of the other $f_2$ (Section 2.1, p. 10). For $\mathsf{MCSP}^*$ the generator is upgraded to **Nisan-Wigderson** (NW94) with designs to make the seeds short enough that $|x|=O(\log n)$ (Section 2.2, p. 11; Lemma 6.6, p. 20, the NW version of the extraction lemma).

Three extra ingredients make the circuit $C$ in the $\mathsf{MCSP}^*$ Yes case exist (Section 2.2, pp. 11-12; Section 8):
- A **locally-encodable, list-decodable error-correcting code** $\mathrm{Amp}$ (Lemma 8.1, p. 24) built from the derandomized XOR / hardness amplification lemma of Impagliazzo-Wigderson (IW97). Local encodability ($O(1/\epsilon\delta)$ nonadaptive queries, depth $O(\log(n/\epsilon\delta))$) lets a small circuit read few input bits; list-decodability ($\mathrm{K}_{1/2-\epsilon}(\mathrm{Amp}^f)$ bounds $\mathrm{K}(f)$) preserves the lower bound.
- **Uhlig's theorem** (Lemma 8.2, Uhl74 / Uhl92): the $r$-wise direct product of any $f:\{0,1\}^{\log\lambda}\to\{0,1\}$ is computable by a circuit of size $O(\lambda/\log\lambda)$ for $r=\lambda^{o(1/\log\log\lambda)}$. This gives the small circuit despite $f_k$ being a random function.
- The reduction is **oracle-independent**: it also shows NP-hardness of $\mathsf{MKTP}^{*A}$ for every oracle $A$ (Section 2.2, footnote 11, p. 6), in deliberate contrast to HW16, which showed MCSP is not reducible to $\mathsf{MCSP}^A$. This is why the negative HW16 evidence does not block $\mathsf{MCSP}^*$.

The most striking conceptual point (Section 2.2, p. 6): the exponential-size circuit lower bound in the No case is obtained "by using almost nothing about circuits" because a size-$s'$ circuit is encoded as a string of $O(s'\log s')$ bits, so a Kolmogorov lower bound $\mathrm{K}(y)\ge s\cdot g$ directly yields a circuit lower bound $s'\ge\Omega(s/\log s)$. This is precisely how the KC00 barrier (which says natural many-one reductions to MCSP would prove $\mathsf{EXP}\not\subseteq\mathsf{P/poly}$) is dodged: randomized reductions can produce a high-circuit-complexity function for free, so the barrier does not apply (Section 1.2, p. 4).

## Relevance to this project

This is the strongest worst-case-hardness foothold the meta-complexity strand currently has, and it maps directly onto several dossier coordinates.

1. **Non-relativizing, with a proof of it.** The result is provably non-relativizing (Appendix B, Proposition B.1), and the author notes it is the first non-relativizing learning-theory result after three decades of the relativization barrier being known (Section 1.1, footnote 2, p. 2). This is a concrete instance of LEARNINGS finding (4): relativization is a finite, mechanical obstruction that a sufficiently structured (here, algorithmic-information-theoretic) argument can step around. The barrier is overcome not by a clever oracle dodge but because the Kolmogorov-complexity accounting is intrinsically about descriptions, which oracles do not relativize cleanly.

2. **The MCSP / MCSP* constructivity crux, LEARNINGS finding (3).** Razborov-Rudich constructivity is the natural-proofs hinge, and MCSP is exactly the object whose tractability would make the natural-proofs property constructive. Proving $\mathsf{MCSP}$ itself NP-hard is still open, but this paper proves the partial variant $\mathsf{MCSP}^*$ NP-hard, the first NP-completeness milestone toward Levin's original goal of NP-completeness of MCSP. Section 3 (Open Problems, p. 12) explicitly identifies "reduce $\mathsf{MCSP}^*$ to $\mathsf{MCSP}$" as the remaining step and argues the large Yes/No gap created here should make that step easier than before.

3. **Average-case vs worst-case, LEARNINGS findings (5) and (6).** Theorem 8.7 ($\mathsf{AveMCSP}$ NP-hard) and the Heuristica connection (Appendix A) sit on the worst-case / average-case bridge. The paper makes the Williams-style point that barriers are passable (finding 6) but flags its own limit honestly: excluding Heuristica needs a non-black-box reduction (Section 3, p. 12), because black-box reductions cannot reduce NP to an average-case NP oracle (FF93, BT06b, AGGM06, BB15, HW20). The author's reductions are algorithmic-information-theoretic and so are subject to that black-box barrier, but Hirahara's earlier Hir18 / Hir21 non-black-box-but-relativizing techniques are subject to the complementary relativization barrier. Combining them is named as the open path.

4. **The Williams algorithm-to-lower-bound spine.** The structural shape here is the same as the Williams spine: a fast-computability or compressibility fact (small program / small circuit in the Yes case) is converted into a lower bound (Kolmogorov / circuit lower bound in the No case). The author makes this explicit (Section 2.2, p. 6): the circuit lower bound falls out of compressibility, not from any explicit-function lower bound. This is the meta-complexity instantiation of "algorithm implies lower bound," which is the dossier's leading-path engine.

## What this enables / what remains open

Mapping to the four research directions:

- **01 (circuit lower bounds toward P/poly).** The No case is genuinely a circuit lower bound for exponential-size circuits obtained almost for free from compressibility. It does not yield an explicit-function lower bound (the hard function is the random $f$, not an explicit one), so it does not directly attack $\mathsf{NEXP}\not\subseteq\mathsf{ACC}^0$ or $\mathsf{TC}^0$. It does sharpen the dictionary "circuit size $\approx$ description length up to $\log$," which is the substrate the $\mathsf{TC}^0$ hinge analysis lives on.
- **02 (natural-proofs evasion, the MCSP crux).** This is the most direct contribution: $\mathsf{MCSP}^*$ is now NP-hard, the partial-function milestone toward NP-hardness of MCSP, the object whose hardness underwrites natural-proofs evasion. Open crux (Section 3, p. 12): reduce $\mathsf{MCSP}^*$ to $\mathsf{MCSP}$, and prove $\mathsf{MCSP}^*$ NP-hard for $\mathsf{AC}^0$ and other unbounded-fan-in circuit classes (the $O(s\log s)$ vs $s^2$ encoding gap blocks the current proof for unbounded fan-in).
- **03 (proof complexity, NP vs coNP).** No direct contribution; the paper is on the function-problem / learning side, not propositional proof systems.
- **04 (GCT, multiplicity obstructions).** No direct contribution. Worth noting only as contrast: GCT hit an occurrence-obstruction no-go (LEARNINGS finding 7), whereas this paper shows a meta-complexity target where the relativization no-go was successfully evaded, reinforcing finding (8) that futures converge on the Williams / meta-complexity spine rather than on GCT.

Concrete open questions this source exposes:
1. Reduce $\mathsf{MCSP}^*$ to $\mathsf{MCSP}$ (total MCSP). The author conjectures the large gap created here makes this tractable (Section 3, p. 12). This is the single highest-leverage follow-up for finding (3).
2. Improve the inapproximability factor of Theorem 1.1 from $n^\epsilon$ to $1.01n$, which by Proposition A.1 (Appendix A) would exclude Heuristica. The author believes this needs a non-black-box reduction exploiting program efficiency in the No case (Section 3, p. 12), and that current techniques face a black-box barrier here.
3. Combine the non-black-box-but-relativizing techniques (Hir18, Hir21) with the black-box-but-non-relativizing techniques here to simultaneously beat both barriers, e.g. by reducing approximate $\mathsf{MINKT}^*$ to GapMINKT of MINKT (Section 3, p. 12). This is exactly LEARNINGS finding (1): barriers compose, and beating one does not beat the other; you must thread them simultaneously.
4. Improve $n^\epsilon$ to $n^{1-o(1)}$ via sophisticated PCP machinery (Section 3, p. 12).
5. NP-hardness of $\mathsf{MCSP}^*$ for unbounded-fan-in $\mathsf{AC}^0$ circuits, blocked by the $O(s\log s)$ vs $s^2$ encoding gap (Section 3, p. 12).
6. NP-hardness of learning $s$-sparse parities by size $s\cdot n^{1/(\log\log n)^{O(1)}}$ programs, which the author says reduces to making the Dinur-Harsha-Kindler PCP "smooth" (every coordinate queried equally likely), conjectured achievable via BHPT20 (Section 3, p. 12).

Caveat on the missing-object thesis (dossier finding 9, the non-algebrizing fast-computable invariant). This paper's central invariant is conditional Kolmogorov complexity $\mathrm{K}(f_i\mid M)$, which is uncomputable in general and is used here only as a counting / accounting device inside a reduction, not as a quantity a fast algorithm computes on the way to a lower bound. So it is not itself the dossier's hoped-for non-algebrizing fast-computable invariant, but it is direct evidence that the right currency for evading relativization is description length / algorithmic information rather than any rational trace, rank, or volume invariant (all of which algebrize). The reduction's oracle-independence ($\mathsf{MKTP}^{*A}$ NP-hard for every $A$, Section 2.2 footnote 11) is also worth flagging to ADVERSARY as a data point on the implied fourth-barrier / bounded-interface-reconstruction thread (finding 10): the reconstruction property (Eq. 1, p. 8) is exactly a bounded-interface reconstruction, where a distinguisher of bounded size yields a short description.

### Barrier scorecard (informal, for ADVERSARY follow-up)
- **Relativizes?** No. Proven non-relativizing for the learning result (Proposition B.1, Appendix B). The MCSP* reduction is, by contrast, oracle-independent in the positive direction ($\mathsf{MKTP}^{*A}$ NP-hard for all $A$), which the author uses to argue the HW16 negative result does not extend to the partial variant (Section 2.2, p. 6). ADVERSARY should reconcile these two facts: the learning lower bound dodges a relativization barrier, while the MCSP* reduction is deliberately oracle-robust.
- **Natural (large + constructive)?** Not applicable in the Razborov-Rudich sense; this is an NP-hardness reduction, not a circuit-lower-bound property over a function class. The relevant comment is that proving total MCSP NP-hard under natural reductions would imply $\mathsf{EXP}\not\subseteq\mathsf{P/poly}$ (KC00); this paper sidesteps that by using randomized reductions that manufacture high-complexity functions, so the KC00 "natural reduction" obstruction does not bite (Section 1.2, p. 4).
- **Algebrizes?** Not analyzed in the paper. The technique is Kolmogorov-complexity-theoretic, not arithmetization-based, so it is a candidate non-algebrizing route worth running through `experiments/_shared/barriers.py` if it is ever encoded as a `ProofTechnique`. Flag for ADVERSARY: the extraction lemma is not obviously an algebraic / low-degree argument, which is promising, but the paper does not claim non-algebrization.
