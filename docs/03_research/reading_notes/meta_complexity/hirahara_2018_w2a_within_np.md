## Summary
The paper presents the first non-black-box worst-case-to-average-case reduction from a problem that is conjectured to lie outside $\mathsf{NP} \cap \mathsf{coNP}$ (an approximation version of the minimum time-bounded Kolmogorov complexity problem MINKT, denoted $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT}$) to a distributional $\mathsf{NP}$ problem $(\mathrm{MINKT}[r], \mathcal{D}^u)$. The main theorem (Theorem 1) shows that if every distributional $\mathsf{NP}$ problem is easy on average (that is, $\mathsf{DistNP} \subseteq \mathsf{AvgP}$), then there is a zero-error randomized polynomial-time algorithm that, on input $(x, 1^t)$, outputs a program $M$ of length $|M| \le \mathrm{K}_t(x) + O((\log|x|)\sqrt{\mathrm{K}_t(x)} + (\log|x|)^2)$ that prints $x$. The contribution is twofold: the construction itself opens the black box of the Nisan-Wigderson generator's security proof (which is why it does not relativize), and a companion research program (Conjecture 5) is proposed: prove $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT}$ is $\mathsf{NP}$-hard under $\mathsf{coNP/poly}$-Turing reductions, which would exclude Heuristica.

## Key definitions and results

### The objects (Section 2, Definitions 7 through 12)
- **Time-bounded Kolmogorov complexity** (Definition 7): for an oracle $A$, a string $x$, and a time bound $t$, $\mathrm{K}^A_t(x) := \min\{|d| : U^A(d) = x \text{ in } t \text{ steps}\}$, where $U$ is a fixed universal Turing machine (Fact 6 gives the polynomial slowdown $p_U$).
- **Approximation version** (Definition 8): $\mathrm{K}^A_{t,\delta}(f) := \min\{|d| : U^A(d)$ outputs a truth table $\mathtt{tt}(g)$ of length $2^\ell$ within $t$ steps with $\mathrm{dist}(f,g) \le 1/2 - \delta\}$, where $\mathrm{dist}(f,g) = \Pr_x[f(x) \ne g(x)]$. This is the bridge between Kolmogorov complexity and the Nisan-Wigderson security proof.
- **MINKT** (Definition 9, after Ko): $\mathrm{MINKT}^A := \{(x, 1^t, 1^s) : \mathrm{K}^A_t(x) \le s\}$. It is in $\mathsf{NP}$ (guess a certificate $d$ of length $\le s$ and check $U(d) = x$ in $t$ steps).
- **The gap promise problem** (Definition 11): $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT}$ has YES instances $(x, 1^t, 1^s)$ with $\mathrm{K}_t(x) \le s$ and NO instances with $\mathrm{K}_{t'}(x) > \sigma(|x|, s)$ for $t' := \tau(|x|, t)$. The search version (Definition 12) asks for a certificate witnessing $\mathrm{K}_{t'}(x) \preceq \sigma(|x|, \mathrm{K}_t(x))$.
- **The distributional NP target** (Definitions 28 through 30): $\mathcal{D}^u$ is the uniform distribution with auxiliary unary input (pick $n \in_R [m]$ and $x \in_R \{0,1\}^n$, output $(x, 1^{m-n})$), and $\mathrm{MINKT}[r] := \{(x, 1^t) : \mathrm{K}_t(x) < r(|x|)\}$. The decision problem $(\mathrm{MINKT}[r], \mathcal{D}^u)$ asks whether $x$ is $r$-nonrandom. Fact 31: this is in $\mathsf{DistNP}$.
- **$r$-random strings** (Definition 15): $x$ is $r$-random with respect to $\mathrm{K}_t$ if $\mathrm{K}_t(x) \ge r(|x|)$; $R_t[r]$ is the set of such strings. **Density** (Definition 16): a set is $\delta$-dense if it captures a $\delta$ fraction of $\{0,1\}^m$.

### Main reduction (Theorem 1, restated and proved on page 20)
Let $r: \mathbb{N} \to \mathbb{N}$ satisfy $n - c\sqrt{n}\log n \le r(n) < n$ for some constant $c > 0$ and all large $n$. Assume $(\mathrm{MINKT}[r], \mathcal{D}^u) \in \mathsf{Avg}_{1/6m}\mathsf{P}$. Then for $\sigma(n,s) = s + O((\log n)\sqrt{s} + (\log n)^2)$ and some polynomial $\tau(n,t)$, there is a zero-error randomized polynomial-time algorithm that on $(x, 1^t)$ outputs a program $M$ of size $|M| \le \sigma(|x|, \mathrm{K}_t(x))$ printing $x$ in $\tau(|x|, t)$ steps.

### The equivalence (Corollary 2 / Corollary 37, page 21)
The implications $1 \Rightarrow 2 \Rightarrow 3 \Rightarrow 4$ hold, and $4 \Rightarrow 2$ under the derandomization hypothesis Promise-$\mathsf{ZPP} = $ Promise-$\mathsf{P}$:
1. $\mathsf{DistNP} \subseteq \mathsf{AvgP}$.
2. $(\mathrm{MINKT}[r], \mathcal{D}^u) \in \mathsf{Avg}_{1/6m}\mathsf{P}$ for some $r$ with $n - O(\sqrt{n}\log n) \le r(n) < n$.
3. There is a zero-error randomized polynomial-time algorithm solving the search version of $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT}$ for $\sigma(n,s) = s + O((\log n)\sqrt{s} + (\log n)^2)$.
4. $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT} \in \text{Promise-}\mathsf{ZPP}$.

The derandomization hypothesis follows from the plausible circuit lower bound $\mathsf{E} \not\subseteq \text{i.o.}\mathsf{SIZE}(2^{\Omega(n)})$.

### The MCSP analog (Theorem 3 / Theorem 50, pages 5 and 26)
$\mathrm{Gap}_\epsilon\mathrm{MCSP}$ (distinguish $\mathrm{size}(f) \le s$ from $\mathrm{size}(f) > 2^{(1-\epsilon)n}s$ given the truth table) satisfies: $\mathrm{Gap}_\epsilon\mathrm{MCSP} \in \text{Promise-}\mathsf{BPP}$ for some $\epsilon > 0$ iff $(\mathrm{MCSP}[2^{\epsilon n}], \mathcal{U}) \in \mathsf{AvgBPP}$ for some $\epsilon > 0$ iff there is a $\mathsf{BPP}$-natural property useful against $\mathsf{SIZE}(2^{\epsilon n})$. Here the worst-case-to-average-case step (the hard $5 \Rightarrow 6$ direction) uses the CIKK generic learning-to-natural-properties reduction (Lemma 52).

### Hardness evidence for GapMINKT (Section 5)
- **Theorem 39 / Proposition 4:** $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT}$ as an oracle breaks every efficiently computable hitting set generator $H: \{0,1\}^n \to \{0,1\}^{n + \tilde{\omega}(\sqrt{n})}$ (any range element has small $\mathrm{K}_t$ and so is non-random). Equivalently no efficiently computable HSG is secure against $\mathsf{P}^A$ for $A$ solving GapMINKT.
- **Corollary 42:** If $\mathrm{Gap}_{\sigma,\tau}\mathrm{MKTP} \in \mathsf{coNP/poly}$ then there is an $\mathsf{NP/poly}$-natural property useful against $\mathsf{P/poly}$ with largeness $1/2$, contradicting Rudich's conjecture. So Rudich's conjecture implies $\mathrm{Gap}_{\sigma,\tau}\mathrm{MKTP} \notin \mathsf{coNP/poly}$.
- **Theorem 43 (Random 3SAT-hardness):** $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT}$ is Random 3SAT-hard. If $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT} \in \mathsf{coNP}$, then Random 3SAT with $m = \Delta n$ clauses (for any $\Delta > 1/\log(8/7) \approx 5.19$) is solvable by an errorless $\mathsf{coNP}$ algorithm with failure probability $\le 2^{-\Omega(n)}$. This beats the Feige-Kim-Ofek $\mathsf{coNP}$ algorithm (which needs $m > O(n^{7/5})$), so under O'Donnell's conjecture that no such $\mathsf{coNP}$ algorithm exists at $m = \Delta n$, we get $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT} \notin \mathsf{coNP}$. This is the source of the abstract's qualifier "unless Random 3SAT is easy for coNP algorithms."

## Techniques and proof ideas

The engine is an inversion of the Nisan-Wigderson generator's security proof, made constructive and efficient, with three nested moves. A builder would reuse the whole pipeline.

1. **Open the security proof of NW (Section 1.8, Lemma 20, page 13).** The NW generator $\mathrm{NW}^f_{m,d}(z) = f(z_{S_1}) \cdots f(z_{S_m})$ over an $(\ell, \rho)$-design $\mathcal{S}$ (Definition 17, constructed via Raz-Reingold-Vadhan, Lemma 18). The classic Nisan-Wigderson theorem says any statistical test $T$ distinguishing $\mathrm{NW}^f$ from uniform yields a small $T$-oracle circuit $C^T$ approximating $f$ (next-bit prediction via a Yao-style hybrid argument). Hirahara's Lemma 20 makes this quantitative as a Kolmogorov-complexity bound: $\mathrm{K}^T_{t,\delta/2m}(f) \preceq \exp(\ell^2/d) \cdot m + d + O(\log(md))$, and shows the certificate (the description of $C^T$) can be found efficiently with oracle access to $T$ by a Markov argument (try $O(m/\delta)$ random choices). The crucial point: the description size is dominated by the output length $m$, so to get a short description we want to *maximize* the seed length.

2. **List-decode to remove the approximation (Lemma 24, Corollary 23, page 14).** Replace $f$ by $\mathrm{Enc}(x)$ for a list-decodable code (concatenated Reed-Solomon and Hadamard, Theorem 22). Then the $1/2 - \delta$ approximate description of $\mathrm{Enc}(x)$ converts to an exact description of $x$ via the list decoder, at additive cost $O(\log(n/\epsilon))$. This upgrades $\mathrm{K}_{t,\delta}$ to ordinary $\mathrm{K}_t$. Tuning $d := \ell\sqrt{m}$ gives certificate length $\approx m + O(\ell\sqrt{m})$, and setting $m \approx \mathrm{K}_t(x)$ (justified because $\mathrm{NW}$ output is not Kolmogorov-random, Lemma 25) yields the $\mathrm{K}_t(x) + O(\ell\sqrt{\mathrm{K}_t(x)} + \ell^2)$ certificate (Theorem 26, Corollary 27, pages 16 and 17).

3. **Manufacture the statistical test from the heuristic algorithm (Section 4, Lemma 33).** This is where the source code enters and the reduction becomes non-black-box. If $(\mathrm{MINKT}[r], \mathcal{D}^u) \in \mathsf{Avg}_{1/6m}\mathsf{P}$, take the errorless heuristic algorithm $M$ and define $T(x, 1^t) := 1$ iff $M(x, 1^t) = 0$. Because there are *few* $r$-nonrandom strings (at most $\sum_{i=0}^{r(n)-1} 2^i \le 2^{r(n)}$ of length $n$), the errorless $M$ must answer "random" on a $\frac{1}{3}$-dense subset of truly random strings (Claim 34 and the density argument). So $T_t \in \mathsf{P}$ is a dense set of $r$-random strings, hence a statistical test for the NW generator. Crucially, the certificate output by the reduction incorporates a *source code* of the errorless heuristic algorithm accepting $T$ (Lemma 14, page 12: for $T \in \mathsf{P}$, $\mathrm{K}_{t'}(x) \le \mathrm{K}^T_t(x) + O(1)$ by hardwiring the polynomial-time machine $M_0$ that accepts $T$ into the description). This dependence on the algorithm's code is exactly what a black-box reduction is forbidden to have.

4. **Make it zero-error (Lemma 36, restatement proof page 20).** Build a Sudan-Trevisan-Vadhan-style pseudorandom generator from a Kolmogorov-random string $w$ found by sampling (the dense set of random strings supplies one whp). The generator's *seed* must be short to enumerate all seeds for derandomization. The paper notes the elegant tension: the security proof is invoked twice, once wanting short seeds (to derandomize) and once wanting long seeds (to get a short description). Raz-Reingold-Vadhan's optimized NW handles both.

5. **MCSP version difficulty (Section 6).** For MCSP the error-correcting code inflates circuit complexity, so the output of $\mathrm{NW}^{\mathrm{Enc}(f)}$ may not be small-circuit-describable. The fix is the CIKK (Carmosino-Impagliazzo-Kabanets-Kolokolova) learning-to-natural-properties reduction (Lemma 52): a natural property is a statistical test for $\mathrm{NW}^{\mathrm{Amp}(f)}$, hardness amplification preserves circuit complexity, and approximate learning suffices for the stated approximation factor. Hirahara-Santhanam's observation that a natural property is essentially an errorless heuristic for MCSP closes the loop (Theorem 51).

## Relevance to this project

This is the **non-black-box engine** the dossier's leading path rides on. Three precise connections.

1. **Why it is non-relativizing (the focus of this note).** Section 1.6 and Section 1.7 are explicit. A black-box nonadaptive reduction would, by Bogdanov-Trevisan, place $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT} \in \mathsf{coNP/poly}$, which is unlikely (Random 3SAT-hardness, Theorem 43). The reduction evades this precisely because the certificate it outputs *embeds the source code of the heuristic algorithm* (Lemma 14, Section 1.8: "this is the crucial part in which our proof is non-black-box; we need a source code of the errorless heuristic algorithm in order to have a short description for $x$"). A black-box reduction treats the heuristic solver as an opaque oracle; here the solver's description is literally a substring of the witness. This is the canonical mechanism by which meta-complexity reductions escape the relativization barrier: the construction inspects the code of an object it is given, which no relativizing argument can do.

2. **The honest caveat: the reduction itself still relativizes (Section 1.7).** This is the discrepancy worth flagging loudly (see discrepancy log below). Hirahara states that although the proof overcomes black-box *reduction* limits, "our proofs do relativize," and Impagliazzo constructed an oracle $A$ with $\mathsf{DistNP}^A \subseteq \mathsf{AvgP}^A$ and $\mathsf{NP}^A \cap \mathsf{coNP}^A \not\subseteq \mathsf{P}^A/\mathsf{poly}$, under which $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT}^A$ is not $\mathsf{NP}^A$-hard under $\mathsf{P}^A/\mathsf{poly}$-Turing reductions. So a *nonrelativizing* technique is still needed to finish Conjecture 5 (NP-hardness of GapMINKT under $\mathsf{coNP/poly}$-Turing reductions). The terminology needs care: the *worst-to-average reduction* is non-black-box (this is established), while the *remaining NP-hardness step* must be non-relativizing (this is open). Both are true and they are different claims about different objects.

3. **Barrier scorecard (informal, applied to the GapMINKT-NP-hardness program, not to a circuit lower bound).** Note the three-barrier checker is calibrated for circuit lower-bound techniques; the natural-proofs axis maps here only loosely (via the property used). The honest reading:
   - **Relativization:** the worst-to-average reduction is non-black-box but still relativizes (Section 1.7). The future NP-hardness step must evade relativization (Impagliazzo's oracle). Verdict for the *program as stated*: NOT yet evaded; this is the explicit open frontier.
   - **Natural proofs:** the reduction *interacts with* the natural-proofs barrier constructively rather than being blocked by it. Corollary 42 turns $\mathrm{Gap}_{\sigma,\tau}\mathrm{MKTP} \in \mathsf{coNP/poly}$ into an $\mathsf{NP/poly}$-natural property against $\mathsf{P/poly}$, so Rudich's conjecture (no such property) becomes evidence for the desired hardness. The MCSP equivalence (Theorem 50) is literally phrased in natural-property language. This source treats the natural-proofs framework as a *source of structure*, not an obstruction, consistent with LEARNINGS finding (3) that the constructivity crux is MCSP.
   - **Algebrization:** not directly analyzed in the paper. The construction is combinatorial / coding-theoretic (NW design, list-decodable codes), not arithmetization-based, so it is not obviously algebrizing, but the paper makes no claim either way. Flag as untested by this source.

## What this enables / what remains open

**Maps to research directions.**
- **02 (natural-proofs evasion / the MCSP crux):** This is the most direct hit. Theorem 50 establishes the exact equivalence "GapMCSP easy on worst case $\iff$ MCSP easy on average $\iff$ a $\mathsf{BPP}$-natural property useful against $\mathsf{SIZE}(2^{\epsilon n})$ exists," and the CIKK plumbing (Theorem 51, Lemma 52) is the constructive bridge. A builder targeting MCSP-based natural-property evasion should treat this as the canonical worst-to-average device.
- **01 (circuit lower bounds via the Williams spine):** indirect but load-bearing. The non-black-box mechanism (embed the algorithm's code in the witness) is the same family of move that the algorithm-to-lower-bound spine relies on, and Section 5's HSG/avoidance framing connects GapMINKT-as-oracle to circuit lower bounds. The derandomization hypothesis Promise-$\mathsf{ZPP} = $ Promise-$\mathsf{P}$ that makes the equivalence two-way is itself a circuit lower bound ($\mathsf{E} \not\subseteq \text{i.o.}\mathsf{SIZE}(2^{\Omega(n)})$).
- **03 (NP vs coNP):** Theorem 43 connects $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT} \notin \mathsf{coNP}$ to Random 3SAT lower bounds for coNP algorithms (O'Donnell's conjecture). This ties meta-complexity to propositional refutation hardness.
- **04 (GCT):** no direct connection in this source.

**Maps to LEARNINGS findings.**
- Finding (3) "the constructivity crux is MCSP": directly confirmed and operationalized by Theorem 50.
- Finding (4) "relativization is finite/mechanical" and finding (9) "the missing object is a non-algebrizing fast-computable invariant": this paper sharpens both. The worst-to-average reduction is non-black-box (it reads code), yet it *still relativizes* (Section 1.7). So "non-black-box" and "non-relativizing" are not the same property, and the missing-object hunt should not assume that opening the black box automatically buys non-relativization. The certificate $\mathrm{K}_t(x)$ here is, in effect, a fast-computable-under-AvgP invariant, but it does not by itself defeat Impagliazzo's oracle.
- Finding (5) "average-case is not worst-case": the entire paper is a partial bridge across exactly this gap, conditional on either $\mathsf{DistNP} \subseteq \mathsf{AvgP}$ (the reduction direction) or a future NP-hardness proof (the program direction).
- Finding (10) "an implied fourth barrier (bounded-interface reconstruction)": the dependence on the heuristic algorithm's *source code* (Lemma 14) is a bounded-interface move worth examining against this proposed fourth barrier. The reduction works precisely because it does not treat the solver as a black-box interface.

**Concrete open questions / cruxes this source exposes.**
1. **Conjecture 5 (the headline open problem):** is $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT}$ NP-hard under $\mathsf{coNP/poly}$-Turing reductions (equivalently $\mathsf{NP} \subseteq \mathsf{coNP}^A/\mathsf{poly}$ for any $A$ solving it)? A positive answer excludes Heuristica from a plausible worst-case assumption. By Section 1.7 this step *must be nonrelativizing* (Impagliazzo's oracle rules out the relativizing $\mathsf{P/poly}$-Turing version). This is the precise place a non-relativizing technique is demanded.
2. **The reducibility subtlety (Section 1.7):** the relativization barrier applies to $\mathsf{P/poly}$ reductions but it is *not known* whether a similar barrier applies to $\mathsf{coNP/poly}$ reductions. Resolving whether $\mathsf{coNP/poly}$-Turing reducibility itself relativizes is a clean sub-question.
3. **HeurP (errors allowed):** the Open Problems paragraph (page 8) notes the reduction crucially uses that there are *few* YES instances in $\mathrm{MINKT}[r]$, so it does not obviously extend from errorless heuristics to heuristics that may err. Extending to HeurP is open.
4. **AvgZPP gap:** Theorem 1 assumes an errorless *deterministic* algorithm; whether $\mathrm{Gap}_{\sigma,\tau}\mathrm{MINKT}$ is easy under $\mathsf{DistNP} \subseteq \mathsf{AvgZPP}$ is open (incorporating random bits into the description spoils the approximation).
5. **Algebrization status (gap in this source):** the paper does not run the algebrization barrier on its construction. Since the dossier's missing object is specifically a *non-algebrizing* fast-computable invariant, an ADVERSARY pass checking whether the NW-plus-list-decoding construction algebrizes would be valuable.

**Discrepancy log.**
- The dossier strand labels this a "meta-complexity device" whose value is being "non-black-box and hence non-relativizing." The paper is explicit (Section 1.7) that the reduction, although non-black-box, *does relativize*. The implication "non-black-box $\Rightarrow$ non-relativizing" is therefore false as stated for this source. The correct reading: the non-black-box reduction relativizes, but the *remaining NP-hardness step* (Conjecture 5) must be non-relativizing. This is a real distinction the project framing should preserve, not silently merge. Reported, not resolved (per SURVEYOR role).
